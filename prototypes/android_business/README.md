## Sources and dependency boundary

SQLite usage follows [Flutter's persistence recipe](https://docs.flutter.dev/cookbook/persistence/sqlite). Android uses [sqflite](https://pub.dev/packages/sqflite); host/subprocess tests use [sqflite_common_ffi](https://pub.dev/packages/sqflite_common_ffi). Lockfile records actual dependency versions/checksums. These references support API usage, not Ubi's performance/security claims.

Protocol and limits are `../validation/WB-01-task-protocol.md`. The prototype must be reworked against an approved production contract before real-data use; it is not a shortcut around G7/G8/G9.
